## 手写 smali 的教训（重要）
- 插入分支不能污染活跃寄存器（v5 有后续 int 读 -> VerifyError）
- 替换锚点必须覆盖完整块（漏尾巴 -> 越界寄存器 VerifyError）
- 外部合成类无法调用 private 方法（IllegalAccessError -> 改 public）
- 构造参数顺序必须与字段捕获对齐（装反 -> NPE）
