# 视频模型能力矩阵（智谱 / Agnes）

> 来源：智谱 CogVideoX 官方文档 + Agnes v2.0/2.5 接口文档 + 今日设备实测（VideoApi 请求日志）
> 更新：2026-09-05

## 一、能力总览

| 能力 | 智谱 cogvideox-flash | 智谱 cogvideox-3 | Agnes 2.5-flash / 2.5 | Agnes v2.0 |
|------|:---:|:---:|:---:|:---:|
| 文生视频 | ✅ | ✅ | ✅ mode=text | ✅ mode=ti2vid |
| 图生视频（单图首帧） | ✅ image_url | ✅ image_url | ✅ mode=reference（images） | ✅ mode=ti2vid |
| **首尾帧** | ❌ | ✅ image_url 传两张图（首帧+尾帧） | ✅ mode=keyframe（first_frame/last_frame 至少一） | ✅ mode=keyframes（extra_body.image 数组） |
| **多图合成** | ❌ | ❌（数组仅限首尾帧两张） | ✅ mode=reference（images ≤5 张 + audios ≤3 段） | ✅ mode=multi_reference |
| 音效（AI 生成音效） | ✅ with_audio（实测 200） | ✅ with_audio | ➖ 无生成音效参数；reference 模式可带参考音频 audios | ➖ |

## 二、参数范围

| 参数 | 智谱 cogvideox-flash | 智谱 cogvideox-3 | Agnes 2.5-flash / 2.5 | Agnes v2.0 |
|------|------|------|------|------|
| 时长 | 5s / 10s（默认 5） | 5s / 10s（默认 5） | 字符串 "4"–"12"（默认 "5"） | 由帧数/帧率决定 |
| 帧率 fps | 30 / 60（默认 30） | 30 / 60（默认 30） | 无 fps 参数（固定） | frame_rate 1–60 |
| 帧数限制 | — | — | — | num_frames ≤441 且满足 8n+1 |
| 分辨率 | app 白名单 8 档（1024x1024、1280x960、960x1280 等；实测 480p→自动映射 1024x1024） | 1280x720、720x1280、1024x1024、1920x1080、1080x1920、2048x1080、3840x2160（默认短边 1080，最高 4K） | **固定 "720P"**（传其它值 HTTP 400） | 三档：480p / 720p / 1080p（不匹配自动映射最近档） |
| 画幅比例 | 由 size 决定 | 由 size 决定 | aspect_ratio：16:9（默认）/ 4:3 / 1:1 / 3:4 / 9:16 | 16:9 / 9:16 / 1:1 / 4:3 / 3:4 |
| 水印开关 | ✅ watermark_enabled | ✅ watermark_enabled | — | — |

## 三、app 内使用注意

- **app 当前 videoModels 配置**：智谱 cogvideox-flash；Agnes 2.5-flash / 2.5 / v2.0。想用首尾帧需把 cogvideox-3 加进智谱的 videoModels
- **时长自定义**：Agnes 2.5 输 8s 直接可用；**智谱会钳到 5/10**（输 8s 实际按 5s 生成）
- **模式枚举**（已修复并实测）：2.5 → text/keyframe/reference；v2.0 → ti2vid/keyframes/multi_reference；智谱无 mode 参数
- **Agnes 媒体要求**：所有图片/音频 URL 需公网可访问，任务完成前保持有效
- **实测记录**（01:35–01:37 设备日志）：Agnes 2.5-flash mode=text → 200 建任务成功；智谱 flash with_audio=true → 200 建任务成功
