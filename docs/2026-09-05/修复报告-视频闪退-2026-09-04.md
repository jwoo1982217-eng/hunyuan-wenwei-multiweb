| # | 崩溃 | 原因 | 修复 |

## 踩坑记录（重要）

1. **禁止手写 dex 二进制补丁改 field_ids**：改 field_id 的 class_idx 会破坏 field_ids 排序 → ART 报 `Out-of-order field_ids` 拒载整个 dex → 所有类 ClassNotFoundException（本次已实测踩坑）
2. **apksigner 调用**：Git Bash 里 `.bat` 调不起来，直接 `java -jar build-tools/36.0.0/lib/apksigner.jar sign` 可用
3. **恢复模拟器配置**：接口配置在 `shared_prefs/api_provider_configs.xml`（key=providers_v1，非 ds_proxy.xml）；无 root 用 `adb shell run-as com.wenwei.deepseekproxy.multiweb` 读写；明文 apiKey 合法（decrypt 对非 enc_v1 前缀直接透传）
4. **adb input text** 空格用 `%s` 转义
5. 卸载重装会清空模拟器内配置，可用 `D:\hunyuan-multiweb\api_provider_configs.xml`（Agnes+智谱，含明文 Key）恢复
