# Agnes 图生视频修复记录（2026-09-06）

## 症状
- 图生视频生成的视频与参考图无关
- v2.0 报 400: mode=multi_reference requires at least 2 images

## 根因
1. executeVideo 的 image_data→image_url 转换段有供应商白名单（bigmodel.cn / stepfun），Agnes 不匹配 → 参考图被静默丢弃
2. v2.0 单图被发成 mode=multi_reference + images=[1张]，上游要求 ≥2 张（最后一张为背景）

## 修复（fix4）
1. 白名单加 contains("agnes")
2. 新增 fixAgnesV20Shape：v2.0 单图 → image 字段 + mode=ti2vid（文档形状）；≥2 张保持 multi_reference

## 抽帧验证（Octocat 参考图）
- 2.5-flash：首帧=参考图剪影原样，中后帧同一角色动画化 ✅
- v2.0：首帧=参考图剪影，中帧站立动画 ✅

## 实测知识
- Agnes 2.5 媒体接受 data:image/xxx;base64 dataURL（"public http(s) URL or valid base64 data"）；过小图片（8x8）被拒
- v2.0 multi_reference：images ≥2，最后一张为背景；单图用 image 字段 + mode=ti2vid
- 2.5 轮询 reference/keyframe 任务必须带 model_name
- prompt 用 <Picture 1> 指代参考图效果更好
